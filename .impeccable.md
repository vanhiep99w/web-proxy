# Design Context

- Audience: one person, using a private website on a desktop or phone. Vietnamese UI.
- Use case: paste a public YouTube link, watch or listen via same-origin server requests, revisit locally stored history. Vercel-only; honest experimental status and useful upstream errors.
- Tone: dark media workspace, quiet and precise, not a marketing page. Warm charcoal, ivory typography, muted terracotta accent. An intimate listening-room feel, clean editorial spacing.
- Accessibility: keyboard navigation, visible focus, native playback controls, reduced-motion support, readable Vietnamese typography served locally.
- Scope: no Spotify, no generic public web proxy, no sign-in with Google or collection of YouTube credentials.
